# PoETools

[简体中文](README.md) | English

[Bilibili Profile](https://space.bilibili.com/3706965307951983)

PoETools is a Windows utility for *Path of Exile* and *Path of Exile 2*. It provides features such as automatic flask use, crafting assistance, campaign guidance, and assisted looting to simplify repetitive in-game actions.

## Features

- **Auto Flask**: Use flasks based on life, mana, or custom conditions. Supports configuration profiles and gamepad mode.
- **Auto Crafting**: Apply crafting strategies based on modifiers, values, groups, and other conditions. Supports manually entered modifiers, wildcard matching, and map value conditions.
- **Campaign Guide**: Display campaign guidance in an overlay.
- **Quick Stash and Retrieval**: Quickly stash or retrieve items, including selection-based operations.
- **Auto Skill**: Trigger skills according to configured conditions.
- **Assisted Looting**: Detect item labels and assist with looting based on target colors and pickup order.
- **Dual-Character Gamepad Support**: Provides character following and button synchronization.
- **Quick Wheel**: Add frequently used features or game commands to a wheel and access them with one hotkey.
- **Quick Commands**: Assign names and hotkeys to in-game chat commands, or trigger them from the quick wheel.
- **Announcements and Updates**: View announcements and update information.

Feature availability and settings may vary by game version, language, and input mode.

## System Requirements

- Windows 10 or Windows 11
- Microsoft Edge WebView2 Runtime
- A system and graphics environment that support Windows Graphics Capture

## Getting Started

1. Launch PoETools and follow the initial setup guide to select the interface language, game version, and game language.
2. Set the game log path when prompted. The log is usually located at `logs/LatestClient.txt` in the game installation directory.
3. Launch the game and confirm that PoETools detects the game window.
4. Configure the features you want to use, then assign hotkeys or add them to the quick wheel.

Some features require coordinates, detection regions, target colors, or an affix database. Use the available drawing and debug tools to verify your settings before enabling them.

## Usage Notes

Auto Crafting reads item information copied to the clipboard, and Quick Commands also uses the clipboard. Announcements, update checks, and related data downloads require a network connection.

Please review the game's terms of service and applicable rules before deciding whether to use automation features.
