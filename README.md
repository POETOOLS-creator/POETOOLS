# PoETools

[English](README.en.md) | 简体中文

[Bilibili主页](https://space.bilibili.com/3706965307951983)

PoETools 是一款适用于《流放之路》和《流放之路 2》的 Windows 辅助工具，提供自动药剂、自动做装、剧情提示、辅助拾取等功能，帮助简化游戏中的重复操作。

## 功能介绍

- **自动药剂**：根据生命、魔力等状态或自定义条件使用药剂，支持配置方案和手柄模式。
- **自动做装**：根据词缀、数值、分组和策略配置执行做装操作，支持手动输入词条、通配匹配和地图数值条件。
- **剧情提示**：显示剧情流程提示，支持悬浮窗。
- **一键存取**：快速存放或取出物品，支持框选等操作。
- **自动技能**：根据配置的条件自动触发技能。
- **辅助拾取**：识别物品标签，根据目标颜色和拾取顺序辅助拾取。
- **手柄双开**：提供角色跟随和按键同步功能。
- **快捷轮盘**：将常用功能或游戏指令添加到轮盘，通过一个快捷键调用。
- **快捷指令**：为游戏聊天指令设置名称和快捷键，也可以通过快捷轮盘触发。
- **公告与更新**：查看公告和更新信息。

部分功能的可用性和配置会根据游戏版本、语言及输入模式有所不同。

## 系统要求

- Windows 10 或 Windows 11
- Microsoft Edge WebView2 Runtime
- 支持 Windows Graphics Capture 的系统和图形环境

## 快速开始

1. 启动 PoETools，按照首次启动引导选择界面语言、游戏版本和游戏语言。
2. 根据提示设置游戏日志路径。日志通常位于游戏根目录的 `logs/LatestClient.txt`。
3. 启动游戏，并确认软件已识别到游戏窗口。
4. 在对应功能页面完成配置，设置快捷键或将功能添加到快捷轮盘。

部分功能需要先配置坐标、识别区域、目标颜色或词缀库。建议使用页面中的绘制和调试功能检查配置后再启用。

## 使用须知

自动做装会读取复制到剪贴板的物品信息；快捷指令也会使用剪贴板。公告、更新检查和相关数据下载需要网络连接。

使用前请自行了解游戏服务条款及相关规则，并根据自己的需求决定是否使用自动化功能。
